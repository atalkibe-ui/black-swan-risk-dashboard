# Внутренний сервер дашборда

Сервис отдает дашборд и предоставляет same-origin API для обновления расчетных
данных. Контейнер со списком потенциальных Black Swan событий заполняется из
выбранного пользователем `.docx` непосредственно в браузере. Файл не передается
на сервер и не отправляется в AI-сервис.

## Настройка

Требуется Node.js 20 или новее.

Задайте серверные переменные окружения:

```text
HOST=127.0.0.1
PORT=8080
DATA_REFRESH_ENABLED=true
DATA_REFRESH_SCRIPT=/opt/black-swan-dashboard/current/deployment/refresh-data.sh
```

## Запуск

```bash
cd server
npm start
```

После запуска страница доступна по `http://127.0.0.1:8080/`. `GET /health`
проверяет процесс, а `GET /ready` — доступность HTML. В продуктивной среде сервис
следует публиковать через внутренний HTTPS reverse proxy с корпоративной
аутентификацией.

Полная схема промышленного размещения и готовые конфигурации находятся в
`deployment/internal-deployment-guide.md`.

Импорт `.docx` не использует API. Браузер проверяет расширение, структуру ZIP/XML,
размер и наличие нумерованного либо маркированного списка минимум из трех
событий. Последний принятый текст хранится в локальном Web Storage пользователя.
